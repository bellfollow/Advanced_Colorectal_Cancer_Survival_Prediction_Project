# 07. R Shiny 대시보드 개발 및 활용

## 1. 대시보드 개요

본 프로젝트에서는 대장암 환자 데이터의 탐색적 분석과 생존 예측 결과를 효과적으로 시각화하고 상호작용할 수 있는 R Shiny 대시보드를 개발했습니다. 이 대시보드는 여러 탭으로 구성되어 데이터의 다양한 측면을 직관적으로 탐색할 수 있게 해줍니다.

- **목적**: 복잡한 임상 데이터를 쉽게 탐색하고, 분석 결과를 직관적으로 시각화하여 의사결정을 지원합니다.
- **대상 사용자**: 임상 연구자, 의료진, 데이터 분석가
- **기술 스택**: R, Shiny, shinydashboard, ggplot2, plotly, DT

## 2. 대시보드 구조 및 주요 기능

### 2.1. 요약 대시보드 (Home)

이 탭은 전체 데이터에 대한 핵심 개요를 제공합니다:

- **핵심 지표 요약**: 
  - 총 환자 수
  - EOCRC(조기 발병, 50세 미만) 환자 수와 비율
  - LOCRC(후기 발병, 50세 이상) 환자 수와 비율
  - 사망자 수와 비율
  - 중앙 생존기간
  - 치료 시행률(수술, 항암치료, 방사선치료)

- **주요 시각화**:
  - 환자 그룹별 병기(Stage) 분포 막대 그래프
  - 생존/사망 분포 파이 차트
  - 주요 변수의 결측률 테이블

이 탭을 통해 사용자는 데이터셋의 전반적인 구성과 품질을 빠르게 파악할 수 있습니다.

### 2.2. 환자군별 탐색 (EDA)

이 탭에서는 변수 간 관계를 탐색하고 환자군별 특성을 비교할 수 있습니다:

- **단변량 분석**: 선택한 변수의 분포를 히스토그램과 밀도 플롯으로 시각화합니다. 환자 그룹(전체, EOCRC, LOCRC)별로 필터링이 가능합니다.

- **다변량 비교 분석**: 두 변수의 관계를 산점도로 시각화합니다. 선택적으로 환자군, 병기, 성별 등의 변수로 포인트 색상을 구분할 수 있습니다.

### 2.3. 생존분석 (Survival Analysis)

이 탭은 Kaplan-Meier 생존 곡선을 통해 다양한 그룹 간의 생존율 차이를 분석합니다:

- **그룹 비교 변수**: 다음 변수를 기준으로 생존 곡선을 비교할 수 있습니다:
  - 환자 그룹 (EOCRC/LOCRC)
  - 성별
  - 암 병기
  - 수술 여부
  - 항암치료 여부
  - 방사선치료 여부
  - KRAS 변이
  - MSI 상태

- **생존 곡선 특징**:
  - 신뢰 구간 표시
  - 로그 랭크 검정 p-값 표시
  - 중앙 생존 기간 선 표시
  - 위험표(risk table) 포함

### 2.4. 변수 상관 및 인사이트 (Insight)

이 탭은 주요 변수 간의 관계와 통계적 요약을 제공합니다:

- **상관관계 히트맵**: 주요 수치형 변수(진단 시 연령, 진단 시 CEA, 수술 시간, 생존 기간) 간의 피어슨 상관계수를 시각화합니다.

- **요약 통계 테이블**: 환자 그룹별(전체, EOCRC, LOCRC)로 다음과 같은 요약 통계를 제공합니다:
  - 수치형 변수: 관측치 수, 평균 및 표준편차, 중앙값 및 IQR
  - 범주형 변수: 각 범주별 빈도 및 백분율

### 2.5. 모델 성능/리포트 (Performance)

이 탭은 개발된 머신러닝 모델의 성능을 비교하고 결과를 보여줍니다:

- **모델 성능 요약 테이블**: 다양한 모델(Random Forest, GBM, XGBoost)과 환자 그룹(total, EOCRC, LOCRC)별 AUC 값을 비교할 수 있습니다.

### 2.6. 추가 탭 (구현 예정)

- **생존예측 시나리오 (Prediction)**: 머신러닝 모델을 활용한 생존 예측 시뮬레이터
- **데이터/코드 다운로드 (Download)**: 분석에 사용된 데이터셋과 코드 다운로드

## 3. 대시보드의 프로젝트 기여

이 대시보드는 다음과 같은 측면에서 프로젝트에 중요한 기여를 했습니다:

- **데이터 품질 관리**: 결측치 패턴을 시각화하여 데이터 전처리 과정에서 필요한 개선점을 식별할 수 있었습니다.

- **가설 검증 지원**: 생존 분석 결과를 직관적으로 시각화함으로써, 다양한 임상 특성이 생존에 미치는 영향에 대한 가설을 빠르게 검증할 수 있었습니다.

- **인사이트 발견**: 변수 간 상관관계와 다변량 분석을 통해 데이터에 숨겨진 패턴과 관계를 발견할 수 있었습니다.

- **결과 커뮤니케이션**: 복잡한 통계 분석 결과를 의료진과 연구자들이 이해하기 쉬운 시각적 형태로 변환하여 효과적인 커뮤니케이션을 지원했습니다.

## 4. 대시보드 실행 방법

대시보드는 다음 명령어를 통해 로컬에서 실행할 수 있습니다:

```R
# R 콘솔 또는 RStudio에서 실행
setwd("shiny_app/")  # Shiny 앱 디렉토리로 이동
shiny::runApp()      # 앱 실행
```

또는 RStudio에서 `ui.R` 또는 `server.R` 파일을 열고 "Run App" 버튼을 클릭하여 실행할 수도 있습니다.

## 5. 향후 개선 계획

현재 대시보드에서 추가로 개발 계획인 주요 기능:

- **예측 모델 활용**: 사용자가 환자 특성을 입력하여 생존 확률을 예측할 수 있는 인터랙티브 예측 시뮬레이터 구현
- **시간에 따른 위험도 변화**: 시간에 따른 위험 계수(hazard ratio) 변화를 시각화하는 기능 추가
- **환자 개인별 생존 곡선**: 특정 환자의 특성에 맞춘 개인화된 생존 곡선 생성 기능
- **모델 결과 해석**: 머신러닝 모델의 변수 중요도와 SHAP 값을 시각화하여 예측 결과의 해석 가능성 향상
