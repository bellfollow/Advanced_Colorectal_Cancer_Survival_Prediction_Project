# 04. 단변량 콕스 회귀 분석 결과 요약

## 1. 개요

이 문서는 `scripts/04_univariate_analysis.R` 스크립트의 실행 결과를 요약합니다. 이 스크립트는 대장암 환자 데이터를 사용하여 각 변수가 생존 기간에 미치는 영향을 개별적으로 분석하는 단변량 콕스 비례 위험 회귀 분석(Univariate Cox Proportional-Hazards Regression)을 수행합니다.

분석은 다음 세 그룹으로 나누어 진행되었습니다.
- **Total**: 전체 환자 집단
- **EOCRC**: 조기 발병 대장암(Early-Onset Colorectal Cancer) 환자 집단
- **LOCRC**: 후기 발병 대장암(Late-Onset Colorectal Cancer) 환자 집단

각 분석 결과는 Hazard Ratio(HR), 95% 신뢰구간(CI), 그리고 p-value를 포함하며, 이를 통해 각 변수의 통계적 유의성을 평가합니다. 또한, p-value가 0.05 미만과 0.20 미만인 변수들을 별도의 CSV 파일로 저장하여 후속 다변량 분석에 사용될 수 있도록 합니다.
